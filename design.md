# Project Overview

Velvet Roast is a premium coffee brand website developed to provide users with a luxurious and immersive coffee experience. The website combines elegant visuals, modern layouts, responsive design, and interactive animations to showcase handcrafted coffee products in a sophisticated manner.

The project is developed using **HTML5, CSS3, and Vanilla JavaScript** with a focus on responsive UI/UX design and reusable components.

---

# Design Goals

- Build a premium coffee brand identity.
- Deliver an elegant and modern user experience.
- Create reusable UI components.
- Ensure responsive layouts for desktop, tablet, and mobile devices.
- Maintain consistency across all pages.
- Use smooth animations for an engaging interface.
