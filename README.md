# ☕ Velvet Roast

A modern and responsive **Premium Coffee Brand Website** developed using **HTML5, CSS3, and Vanilla JavaScript**. Velvet Roast showcases handcrafted coffee products through an elegant interface featuring smooth animations, interactive product cards, a cinematic hero section, and a luxurious coffee-inspired design.

# 📖 Project Overview

Velvet Roast is designed to deliver a premium coffee browsing experience. The website combines clean layouts, engaging animations, and responsive design principles to create an attractive and user-friendly interface for coffee enthusiasts.
